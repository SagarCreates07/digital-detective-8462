# Mission 1 — Know your computer

## 1. Task / objective
The mission asked me to explain how a computer takes input, processes it, gives output and stores results. I also had to identify hardware, software and computer-based systems.

## 2. Work completed
I traced one activity using IPOS, made a table of hardware and software, and listed three computer systems from everyday life.

### Task 1.1 — IPOS
**Activity chosen:** Typing a note and saving it

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I type the words of my note using the keys | Keyboard |
| Processing | The computer works out which keys I pressed and turns them into letters | CPU and RAM |
| Output | The letters appear on the screen as I type | Screen |
| Storage | I press Save and the note file is kept on the computer | SSD |

I give input by typing on the keyboard. The CPU and RAM process the key presses, and the screen shows the text as output. When I save, the file is stored on the SSD so it is still there after I switch off.

## 4. My understanding
IPOS stands for Input, Processing, Output and Storage. These are the four jobs a computer does: it takes something in, works on it, shows a result and keeps it for later. Hardware is the physical parts I can touch, like the keyboard and screen. Software is the programs that run on the hardware. An operating system runs the whole computer, an application helps me do a task, and a utility helps maintain or check the computer.

## 5. Difficulties faced
I was not sure at first whether some programs were applications or utilities.

## 6. How I resolved them
I thought about what each program is used for. If it helps me do a task, it is an application, and if it helps check or maintain the computer, it is a utility.
